# DronT16

## Система сопровождения выбранной цели для FPV-дрона

Проект Олежки и Машеньки — бортовая система для Raspberry Pi 5, которая
получает изображение со своей камеры, показывает пилоту служебное OSD и по
явной команде сопровождает выбранный объект.

Пилот сам наводит камеру и выбирает цель. Система не распознаёт классы объектов,
не ищет новую цель после потери и не захватывает другой объект самостоятельно.

```text
DIRECT  →  CAPTURE  →  FOLLOW
   ↑          ↓          ↓
   └──────── Отбой ──────┘
```

Отдельный CRSF-мост Raspberry Pi передаёт команды между приёмником и
полётником. При потере связи работает failsafe: удержание высоты и горизонта,
разворот на заданное время и ожидание восстановления связи.

Главный документ проекта — [PROJECT.md](PROJECT.md). Здесь находится только
краткое описание; архитектура, распиновка, конфигурации и планы испытаний
ведутся в `PROJECT.md` и документации `docs/`.

## Быстрый запуск

```bash
./run.sh
```

Локальная проверка привязки датчиков без Raspberry и без команд полётнику:

```bash
./run.sh sensor-test
```

Результат теста сохраняется в `diagnostics/raspberry/sensor_binding_test.log`,
каталог не публикуется в Git. Этот тест проверяет программный MSP-контракт, а не реальные
GPS, магнитометр или камеру.

Режим failsafe выбирается в секции `[failsafe]` файла `config/dront16.toml`:

```toml
[failsafe]
mode = "real"  # takeover при реальном тайм-ауте CRSF-кадров
# mode = "CH7" # стендовая имитация потери связи тумблером
```

Секреты, ключи, резервные копии устройств и коммерческий каталог `security/`
в репозиторий не входят.
