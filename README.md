# DronT16

Локальная система назначения и сопровождения выбранной пилотом цели для FPV-дрона.

Проект разделён на два этапа применения:

- **T16** — отладочная платформа без управления дроном;
- **Raspberry Pi 5** — будущая бортовая рабочая платформа.

Базовые команды системы: «Захватить», «Следить», «Автопилот» и «Отбой».
Система не распознаёт классы объектов, не ищет новую цель самостоятельно и
после потери цели требует нового явного захвата пилотом.

Текущий этап — документация и безопасное проектирование. Реализация начинается
после проверки оборудования и выбора системы управления дроном.

Подробная спецификация находится в [PROJECT.md](PROJECT.md).
