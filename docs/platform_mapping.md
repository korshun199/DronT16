# Сопоставление платформ H и R

## Назначение

Проект использует одну программную логику на двух платформах:

- `H` — ноутбук для разработки и проверки;
- `R` — Raspberry Pi 5 для рабочей бортовой системы.

Перенос проекта не должен требовать изменения модулей захвата, сопровождения,
расчёта направления или Betaflight MSP. Меняется только выходной адаптер.

## Сопоставление устройств

| Функция | Платформа H — ноутбук | Платформа R — Raspberry Pi 5 |
|---|---|---|
| Камера | цифровая USB-камера ноутбука | цифровая камера Raspberry Pi по CSI-шлейфу |
| Обработка | общий код DronT16 | общий код DronT16 |
| Прямой видеотракт | цифровая камера → веб-морда на HDMI-мониторе | цифровая камера → J7 |
| Обработанный видеотракт | DronT16 → веб-морда на HDMI-мониторе | DronT16 → J7 |
| Диагностика | та же веб-морда на HDMI-мониторе | веб-морда Raspberry Pi |
| Команда стика | программный тестовый вход | адаптер выбранной системы управления |
| Полётник | отсутствует, MSP только dry-run | Betaflight, после отдельной проверки |

## Единственное платформенное изменение

В рабочей схеме меняется только выходной адаптер:

```bash
# Ноутбук H: веб-морда открыта на HDMI-мониторе
VIDEO_OUTPUT="WEB"

# Raspberry Pi R: рабочее видео идёт на J7
VIDEO_OUTPUT="J7"
```

Остальные параметры и модули не изменяются. На ноутбуке веб-морда является
единственным экраном, а на Raspberry Pi она остаётся диагностическим каналом и
не является рабочим видеовыходом J7.

## Программный интерфейс выхода

```text
Общий видеокадр DronT16
          ↓
    OutputRouter
       ├── HDMIOutput  на платформе H
       └── J7Output    на платформе R
```

`HDMIOutput` и `J7Output` должны принимать одинаковый обработанный кадр. Поэтому
переключение `DIRECT`, `CAPTURE`, `FOLLOW` и `RETURN` остаётся общей логикой
DronT16, а особенности окна HDMI или композитного J7 находятся только внутри
выходного адаптера.

## Камера

Камера также подключается через общий интерфейс источника кадров. На H источник
— USB-камера, на R — CSI-камера Raspberry Pi. Выбор конкретного драйвера не
должен попадать в верхние уровни сопровождения.

До появления Raspberry Pi и проверки J7 на ноутбуке проверяется общий формат
кадров и обработка. Работу настоящего CSI-источника, J7 и команды стика можно
подтвердить только на платформе R.
