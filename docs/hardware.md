# Аппаратная конфигурация

## Подтверждено

- бортовой компьютер: Raspberry Pi 5;
- рабочая видеокамера: камера для Raspberry Pi 5, точная модель не выбрана;
- отладочная платформа: T16.

## Каналы видео и просмотра

- на ноутбуке тестовый источник — USB-камера ноутбука, выбранная индексом
  OpenCV или подтверждённым `/dev/videoN`;
- на Raspberry Pi 5 рабочий источник — камера Raspberry Pi, точный путь и
  драйвер будут подтверждены после подключения камеры;
- отладочный просмотр — HDMI-монитор ноутбука через окно OpenCV;
- рабочий просмотр — веб-морда Raspberry Pi в локальной сети.

## Цифровой OSD

Видеопоток дрона и видеовход передатчика не подключаются к Raspberry Pi и не
обрабатываются DronT16. Raspberry Pi использует собственную камеру, а работает
только как промежуточный обработчик цифрового OSD между двумя UART.

Предварительно предоставленные физические пины Raspberry Pi: `7`, `8`, `10`,
`29`. Направления RX/TX, распределение по двум UART, уровни сигналов и общий
GND ещё не подтверждены. Подключение запрещено до проверки схемы конкретной
платы.

Режим DronT16 должен отображаться одновременно на HDMI-тестовом экране и в
цифровом OSD-потоке пилота.

## Команды режимов

На ноутбуке для отладки используются клавиши:

1. «Захватить»;
2. «Следить»;
3. «Автопилот»;
4. «Отбой».

В рабочем режиме Raspberry Pi 5 эти же четыре команды должны приходить от
полётного контроллера. Способ передачи, протокол, распиновка и уровни сигналов
будут определены после выбора системы управления дроном.

## Не определено

- система управления дроном;
- полётный контроллер и его прошивка;
- протокол обмена;
- видеовход и способ вывода изображения;
- назначение физических органов управления T16;
- распиновка и уровни сигналов;
- точная модель камеры Raspberry Pi и её видеодрайвер.

До подтверждения этих сведений подключение внешних сигналов и выбор протокола
не выполняются.
