# Аппаратная конфигурация

## Подтверждено

- бортовой компьютер: Raspberry Pi 5;
- рабочая видеокамера: камера для Raspberry Pi 5, точная модель не выбрана;
- отладочная платформа: T16.

## Не определено

- система управления дроном;
- полётный контроллер и его прошивка;
- протокол обмена;
- видеовход и способ вывода изображения;
- назначение физических органов управления T16;
- распиновка и уровни сигналов.

До подтверждения этих сведений подключение внешних сигналов и выбор протокола
не выполняются.
