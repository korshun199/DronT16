# Ноутбучная модель Raspberry Pi 5

Пока бортовой платы нет, вся логика DronT16 моделируется на ноутбуке.

## Соответствие устройств

```text
Ноутбук                         Будущая система
USB-камера ноутбука        →    камера Raspberry Pi 5
Python/OpenCV на ноутбуке  →    DronT16 на Raspberry Pi 5
HDMI-монитор                →    изображение в очках пилота
Клавиши 1..4               →    команды от полётного контроллера
```

## Ограничение модели

В симуляции USB-камера ноутбука является источником кадров для алгоритма
Raspberry. Обработанный кадр выводится на HDMI как тестовый пилотский экран с
наложением статуса и маркера цели.

Это только модель цепочки обработки. Реальный видеопоток дрона и камера
передатчика в работу не включаются: в настоящей системе они проходят своим
штатным трактом, а Raspberry изменяет только цифровой OSD между двумя UART.

## Команды симуляции

- `1` — имитация команды полётного контроллера «Захватить»; пилот наводит
  камеру, чтобы объект оказался в центральном квадрате;
- `2` — имитация команды «Следить»;
- `3` — имитация команды «Автопилот»; пока всегда отклоняется;
- `4` — имитация команды «Отбой».

Позже клавиатурный источник заменяется адаптером команд от полётного
контроллера. Машина состояний, обработка потери цели и правила запрета
переключения цели при этом не меняются.

## Два представления

В симуляции один обработанный кадр может выводиться одновременно:

- в окно OpenCV на HDMI — модель изображения пилота;
- в веб-морду — модель диагностического просмотра Raspberry.

В рабочей системе HDMI-окно ноутбука заменяется цифровым OSD-потоком,
переданным на передатчик. Веб-морда остаётся отдельным диагностическим каналом.

Для внешнего HDMI-монитора приложение поддерживает `--hdmi-x`, `--hdmi-y` и
`--fullscreen`. Координаты соответствуют общей виртуальной рабочей области
Ubuntu и зависят от расположения монитора относительно экрана ноутбука.
