# План проверки

## Этапы

1. `DIRECT`: видео с камеры проходит без обработки.
2. `CAPTURE`: команда «Захватить» включает рамку и наложение.
3. `FOLLOW`: команда «Следить» сохраняет наложение и готовит отдельный канал
   команд полётнику.
4. Потеря цели не приводит к выбору другого объекта.
5. `RETURN`: потеря связи отключает видео и проверяется безопасная передача
   возвратных команд на виртуальном стенде.
6. Восстановление связи возвращает систему в `DIRECT`.
7. «Отбой» из каждого активного состояния возвращает систему в `DIRECT`.
8. Только после этого — стенд обмена с реальным полётным контроллером.

## Критерий первого прототипа

Первый прототип не выдаёт команд моторам и автопилоту. Он доказывает корректный
захват, сопровождение, отображение состояния и безопасное поведение при потере
цели.
