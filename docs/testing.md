# План проверки

## Этапы

1. Воспроизведение записанного видео без оборудования дрона.
2. Захват цели отдельной командой пилота.
3. Сопровождение выбранной цели и экранная индикация.
4. Потеря цели без переключения на другой объект.
5. Повторный захват только после новой команды.
6. Проверка «Отбоя» из каждого активного состояния.
7. Только после этого — виртуальный стенд обмена с полётным контроллером.

## Критерий первого прототипа

Первый прототип не выдаёт команд моторам и автопилоту. Он доказывает корректный
захват, сопровождение, отображение состояния и безопасное поведение при потере
цели.
