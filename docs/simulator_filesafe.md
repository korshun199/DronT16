# simulator_filesafe

Автономный текстовый симулятор failsafe. Он не открывает реальные UART/CRSF/MSP
порты и не отправляет команды полётнику.

## Запуск

```bash
./scripts/simulator_filesafe.sh
```

Все параметры сценария находятся в `config/simulator_filesafe.toml`.
Журнал одновременно выводится в терминал и перезаписывается в
`simulator_filesafe.log`. Файл журнала не добавляется в Git.

Потеря связи моделируется тумблером CH7/AUX3. Верхнее положение создаёт
событие `LINK_LOST`, нижнее — `LINK_OK`. Канал и пороги можно изменить в
секции `[control]`.

Команда `DISARM` берётся из отдельного канала CH5/AUX1. Для текущей настройки
передатчика низкое raw-значение CH5 означает DISARM, а высокое — ARM. Низкое
значение немедленно отключает виртуальные моторы и блокирует дальнейшие команды до
перезапуска симулятора. Реальный полётник и реальные моторы симулятор не
затрагивает.

Симулятор показывает:

- виртуальные пакеты полётника и CRC;
- состояния CRSF/MSP-портов;
- объект и его состояние в памяти;
- потерю связи и использование последнего пакета;
- разворот на заданный угол;
- команды полётнику только текстом с пометкой `SIMULATED`;
- переход в возврат и восстановление связи.
