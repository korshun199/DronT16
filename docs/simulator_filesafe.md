# simulator_filesafe

Текстовый симулятор failsafe и журнал управляемого CRSF-моста. Симулятор не
открывает реальные UART/CRSF/MSP порты; реальный мост работает отдельно и
передаёт кадры полётнику только по описанной стендовой логике.

## Запуск

Старый автономный симулятор удалён из рабочей конфигурации. Его сценарии
сохраняются в истории Git как архив испытаний и не запускаются через `run.sh`.

Исторические параметры сценария находятся в секциях `[simulation.*]` файла
`config/dront16.toml`.
Журнал одновременно выводится в терминал и дописывается в
`simulator_filesafe.log`. История не перезаписывается, файл журнала не
добавляется в Git.

Потеря связи моделируется тумблером CH7/AUX3. Верхнее положение создаёт
событие `LINK_LOST`, нижнее — `LINK_OK`. Канал и пороги можно изменить в
секции `[control]`.

Команда `DISARM` берётся из отдельного канала CH5/AUX1. Для текущей настройки
передатчика низкое raw-значение CH5 означает DISARM, а высокое — ARM. Низкое
значение немедленно отключает виртуальные моторы и блокирует дальнейшие команды до
перезапуска симулятора. Реальный полётник и реальные моторы симулятор не
затрагивает.

Управляемый мост при CH7 сначала запоминает последний полный RC-кадр, затем
подавляет свежие кадры и плавно уменьшает канал газа до CRSF-ноля с частотой
входящего потока.
При возврате CH7 живой поток восстанавливается. DISARM имеет приоритет и
возвращает живое управление после отправки кадра с выключенным ARM.

Симулятор показывает:

- виртуальные пакеты полётника и CRC;
- состояния CRSF/MSP-портов;
- объект и его состояние в памяти;
- потерю связи и использование последнего пакета;
- разворот на заданный угол;
- команды полётнику только текстом с пометкой `SIMULATED`;
- переход в возврат и восстановление связи.
