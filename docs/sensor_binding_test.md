# Локальный тест привязки датчиков

Команда:

```bash
./run.sh sensor-test
```

Тест выполняется только на ноутбуке и использует настоящий `MspParser`, но
синтетические ответы MSPv1. Он проверяет:

- сборку дробленого UART-потока и XOR checksum;
- барометр/вариометр и attitude через существующие MSP-ответы;
- сырые оси магнитометра и диагностический курс `atan2(Y, X)`;
- GPS fix, число спутников, координаты, высоту, скорость и курс;
- ограничение свежести GPS и отказ при отсутствии fix;
- наличие привязки фронтальной камеры в единой конфигурации.

Скрипт не открывает `/dev/tty*`, не включает камеру, не запускает CRSF-мост и
не отправляет команды Betaflight. Поэтому успешный результат подтверждает
только программный контракт и парсинг. Реальные датчики HAKRCF405V2 и GPS
проверяются отдельным этапом после подключения Raspberry.

Подробный журнал сохраняется в `runs/sensor_binding_test.log`; каталог `runs/`
исключён из Git. Формат `MSP_RAW_GPS` разбирается как `fix`, `satellites`,
latitude/longitude в `1e-7` градуса, altitude в метрах, speed в `cm/s`, course
в `0.1` градуса и необязательный `HDOP` в `0.01`.
