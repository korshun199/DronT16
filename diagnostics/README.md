# Диагностика DronT16

Это единственное локальное место для материалов испытаний. Каталог не
публикуется в Git: в репозитории остаётся только эта памятка.

- `raspberry/` — журналы, автоматически скачанные с Raspberry Pi.
- `pulseview/` — записи логического анализатора (`.sr`) и их настройки
  (`.pvs`). D6 — вход CRSF в Raspberry, D7 — выход CRSF к FC.
- `video/` — локальные тестовые видеозаписи.
- `analysis/` — производные текстовые разборы сохранённых журналов.

После ARM → DISARM Машенька забирает последний журнал одной командой:

```bash
./scripts/rpi.sh copy-log
```

Скрипт берёт самый новый файл `simulator_filesafe_*.log` с Raspberry и не
перезаписывает уже сохранённую локальную копию. Все дальнейшие разборы ведутся
только по файлам из этого каталога.
