# Конфигурация DronT16

Единый формат конфигурационных файлов проекта — TOML.

Каждый параметр должен иметь комментарий на русском языке. Значения по
умолчанию и безопасные ограничения хранятся рядом с параметрами. Секреты,
ключи и персональные данные в конфигурационные файлы проекта не добавляются.

Файл `follow.toml` содержит настройки модуля сопровождения. При добавлении
нового модуля его конфигурация также создаётся в формате TOML с русскими
комментариями.

Файл `osd.toml` содержит размеры центрального квадрата, перекрестия, рамок,
точки цели и подписей экранного OSD. Для уменьшения квадрата изменяется
параметр `osd.capture_box_size`.
